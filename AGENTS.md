# Protokol Operasional AI & Alur Eksekusi MMZ Booking Management

Dokumen lengkap panduan operasional agen AI dapat diakses di:
👉 **[docs/AGENTS.md](docs/AGENTS.md)**

### Ringkasan Cepat Protokol AI:
1. **Pre-Flight Checks Wajib:** Periksa `docs/prd.md`, `docs/ARCHITECTURE.md`, dan `docs/DESIGN_SYSTEM.md` sebelum menulis kode.
2. **Penegakan Skill:** Terapkan standar `backend-craft` (Library-First, input validation Zod, resilient pool) dan `ui-taste` (Anti-UI slop, Zentra clean aesthetics).
3. **Standar Bahasa:**
   - **Git Commit Messages:** Wajib **Bahasa Inggris** (Conventional Commits: `feat:`, `fix:`, dll.).
   - **UX Writing Antarmuka:** Wajib **100% Bahasa Indonesia** (Label, button, empty state, toast message, dialog konfirmasi).
4. **Alur Eksekusi:** Terdiri dari 10 tahapan terstruktur mulai dari koneksi basis data hingga visualisasi analitik.
