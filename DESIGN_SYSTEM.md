# MMZ Studio Foto — Design System Specification

Dokumen spesifikasi desain sistem lengkap dapat diakses di:
👉 **[docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md)**

### Ringkasan Desain Sistem:
- **Inspirasi Visual:** Zentra Modern SaaS Dashboard (Minimalist, Anti-UI-Slop, High-Information Density).
- **Surface & Canvas:** Canvas `#F4F5F7` netral lembut dengan kartu putih bersih `rounded-3xl` (24px) dan *ambient diffuse drop shadow*.
- **Pill Micro-Interactions:** Navigasi atas dengan tab aktif kapsul gelap (`#18181B`), filter bar berbentuk kapsul, dan status badges semantik.
- **Harmonisasi Warna Studio & Status:**
  - **Studio 1:** Royal / Electric Blue (`#2563EB`)
  - **Studio 2:** Emerald Green (`#059669`)
  - **Status Lunas / Terkonfirmasi:** Emerald
  - **Status DP Diterima / Menunggu DP:** Amber
  - **Status Batal:** Crimson Rose
- **Hero Insight Card:** Gradien hangat ke dingin (*sunset-to-ocean mesh*) dengan aksen *frosted glass* untuk metrik analitik Owner.
